Cómo configurar el reenvío

Primero pulse Activar reenvío automático y copie la dirección. Luego configure su correo. Puede usar Gmail y Outlook a la vez; los documentos llegan a la misma bandeja de DTEs.

Gmail — 1. Verificar la dirección (en el ordenador; esta pantalla no está en el celular)

  1. Gmail → Ajustes → Ver todos los ajustes → pestaña Reenvío y correo POP/IMAP.
  2. Añadir una dirección de reenvío → pegue la de SmartPyme → Siguiente → Continuar → Aceptar.
  3. Gmail envía un correo de verificación aquí. En unos minutos verá el código o el enlace en esta tarjeta. Confírmelo en Gmail y recargue Ajustes.

Gmail — 2. Reenviar solo facturas (filtro)

El reenvío general manda todos los correos nuevos, excepto el spam. No lo deje encendido. Inhabilite el reenvío automático y use un filtro (la dirección solo aparece después de verificarla).

  1. En el cuadro de búsqueda de Gmail: Mostrar opciones de búsqueda.
  2. Criterio útil: correos con adjunto (y el remitente de Hacienda o su proveedor, si siempre es el mismo).
  3. Crear filtro → marque Reenviar → elija la dirección de SmartPyme → Crear filtro.

Gmail no reenvía el spam. Si una factura no llega, revísela en Spam y márquela como “No es spam”. En Google Workspace un administrador puede prohibir el reenvío.

Outlook.com

  1. Configuración → Correo → Reenvío.
  2. Activar reenvío → pegue la dirección de SmartPyme. Microsoft pedirá verificación en dos pasos de su cuenta, no un código aquí.
  3. Marque conservar una copia si quiere quedarse el original → Guardar.

Eso reenvía todo el correo nuevo. Para solo facturas, use una regla “Reenviar a” o “Redirigir a”.

Microsoft 365 / correo de empresa

Cree una regla Reenviar a / Redirigir a. Si aparece el error 5.7.520, TI bloqueó el reenvío externo: pídales que permitan ingest.smartpyme.site, o use Conectar Gmail / IMAP.

Qué debe llevar el correo

  • Adjunto JSON (El Salvador) o XML (Costa Rica). Un PDF solo no se importa.
  • Los documentos aparecen en Bandeja de DTEs para revisión; no se contabilizan solos.

Si no llega nada

  • ¿La tarjeta está Activa y el filtro usa esta misma dirección?
  • ¿Confirmó la verificación de Gmail?
  • ¿El correo está en spam de Gmail? ¿Es solo PDF?
  • Último correo con fecha y último DTE vacío: el reenvío funciona, pero ese mensaje no traía JSON/XML.
